## ⚙️ Как устроен CI/CD

Проект использует **GitHub Actions** для настоящего Continuous Deployment (CD).

Файл конфигурации: `.github/workflows/ci-cd.yml`

**Пайплайн работает так:**
1. При пуше в `main` запускается джоб `build`.
2. Устанавливаются зависимости (`npm ci`).
3. Проект собирается (`npm run build`).
4. Готовые файлы (артефакт `dist`) передаются в джоб `deploy`.
5. `deploy` публикует статику на GitHub Pages.

> 🔒 **Гейтинг:** Если сборка падает с ошибкой, деплой не запускается. Это гарантирует, что на живом сайте всегда работает только проверенный код.
